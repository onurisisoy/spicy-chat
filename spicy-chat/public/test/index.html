Test senaryosu

  1. Paneli bir sekmede aç, giriş yap (şifre: .env → PANEL_PASSWORD).
  2. Başka sekmede bir test sitesi aç, widget'tan yaz.
  3. Mesaj panelde Türkçe görünür (mock çeviride [sv→tr] etiketiyle).
  4. Panelden Türkçe cevap yaz; widget'ta müşterinin dilinde görünür.
  5. Paneldeki E-posta iste → widget'ta e-posta formu çıkar.
  6. Test sekmesini kapat, panelden cevap yaz → EMAIL_DEBOUNCE_SECONDS sonra e-posta var/outbox/ klasörüne düşer.
  7. Durumu Offline yap → widget "mesaj bırakın" moduna geçer.
